How to prepare the file
  • The Excel template is the easiest way: the columns that have a set of choices (your locations, categories, Yes/No and so on) have a dropdown in each cell, and each header has a note saying what goes in it. The lists are your records when you download it, so download a fresh one when you've added more. You can still type a value that isn't in a list, or paste values in, and they're checked when you import.
  • Upload an Excel Workbook (.xlsx). Only its first sheet is read. If your data is in a CSV or an older .xls file, open it in Excel and save it as an Excel Workbook, or paste it into the template.
  • The first row must be the headers below, in any order. Headers aren't case sensitive, and spaces count as underscores. Columns that aren't required can be left out.
  • Each row after that is one new record. Blank rows are skipped.
  • Rows that pass every check are imported. Rows with a problem are skipped, and the results page lists each one with the reason, so you can fix them and import just those rows again.
  • Importing only adds records. It never changes or deletes existing ones.
