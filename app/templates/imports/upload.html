How to prepare the file
  • Save it as CSV. From Excel, "CSV UTF-8" is best, but "CSV (Comma delimited)" works too.
  • The first row must be the headers below, in any order. Headers aren't case sensitive, and spaces count as underscores. Columns that aren't required can be left out.
  • Each row after that is one new record. Blank rows are skipped.
  • Rows that pass every check are imported. Rows with a problem are skipped, and the results page lists each one with the reason, so you can fix them and import just those rows again.
  • Importing only adds records. It never changes or deletes existing ones.
